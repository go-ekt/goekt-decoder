## 🚀 Overview | نبذة عامة
**GoEKT Paper Decoder** is not just a translator; it is a **Scientific Bridge**.
Designed specifically for Arab researchers, students, and futurists, this tool leverages the cognitive power of **Google Gemini AI** to dismantle the language barrier in academia.

Unlike standard translation tools that corrupt scientific meaning, GoEKT Decoder is engineered with a **Strict Terminology Protocol**: it Arabizes the context while preserving the integrity of scientific terms in their original English form.

> *"Language should be a bridge, not a barrier to the future."* — GoEKT Manifesto.

## ⚡ Core Features | الميزات الجوهرية

### 1. 🧠 Scientific Integrity Protocol
The core algorithm ensures that technical terms remain precise.
* **Input:** "Neural Networks optimize weights."
* **Output:** "تقوم الشبكات العصبية (Neural Networks) بتحسين الأوزان (Weights)."

### 2. 🎯 Academic Tone Calibration
The AI is fine-tuned to output **"Academic Arabic" (الفصحى العلمية)**, avoiding colloquialisms or weak phrasing. It reads like a paper written by a native Arab professor.

### 3. 🎨 GoEKT Visual Identity
Built with a custom UI skin reflecting the **GoEKT Brand System**:
* **Primary:** Navy Blue (`#0A192F`)
* **Accent:** Cyan (`#64FFDA`)
* **Typography:** Modern & Clean.

## 🛠️ How It Works | كيف تعمل الأداة

1.  **Engine:** The app uses `google.generativeai` library to connect with Gemini Pro/Flash models.
2.  **Interface:** Built on `Streamlit` for a responsive, mobile-first experience.
3.  **Processing:**
    * User inputs text.
    * System injects the "GoEKT Translator Persona" prompt.
    * AI processes the terminology and grammar.
    * Output is rendered in formatted Markdown.
